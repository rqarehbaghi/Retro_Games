# Everything the project imports. `bash setup.sh` installs this into ./venv,
# and `python tools/doctor.py` afterwards reports what pip CANNOT install --
# ffmpeg, the fonts, a ROM, a GPU driver, a voice model's weights.
#
# Known-good on the machine this was last verified on (Ubuntu in WSL2,
# Python 3.14): numpy 2.5.2, gymnasium 1.3.0, stable-retro 1.0.1,
# stable-baselines3 2.9.0, torch 2.13.0+cu130, opencv-python-headless 5.0.0.93,
# Pillow 12.3.0, pygame-ce 2.5.8, matplotlib 3.11.1. Nothing is pinned here on
# purpose: the torch build in particular depends on the CUDA version of the
# machine, and pinning one would break every other machine.

# ---------------------------------------------------------------- the core --
stable-retro                 # the emulator and the integration format
gymnasium                    # the env API everything is written against
numpy
stable-baselines3[extra]     # PPO; pulls torch, which rl/afterstate.py also uses directly
torch                        # listed explicitly because this project imports it directly

# train.py's frame preprocessing (grayscale/resize). The HEADLESS build: no GUI
# libraries, which matches a server and does not fight pygame's own SDL.
opencv-python-headless

# Every overlay, every panel and the whole stats card are drawn with Pillow --
# overlays.py, tools/progression/chart.py, tools/progression/video.py.
Pillow

# The interactive play window and the gamepad (play_engine.py, tools/probe_pad.py).
# pygame-ce is the maintained fork and is what `import pygame` resolves to.
pygame-ce

# Training plots in rl/afterstate.py.
matplotlib

# GPU video encoding (NVENC) is NOT a pip package -- it comes from the NVIDIA
# driver plus ffmpeg. `bash tools/check_nvenc.sh` (run by setup.sh) tests it and
# explains any fix. Renders use libx264 by default: on a WSL2 laptop NVENC
# measured slower and failed 3 of 18 encodes (see overlays.py).

# ------------------------------------------------- writers (pick any ONE) --
# No writer needs a pip package or separately billed API. setup.sh installs the
# Codex CLI; authenticate it inside WSL with `codex login --device-auth` to use
# the existing ChatGPT subscription. Ollama remains the local free fallback:
# `curl -fsSL https://ollama.com/install.sh | sh`, then
# `ollama pull qwen3:30b-a3b`.

# ------------------------------------------------------- voice (optional) --
# Only for --voice. Nothing below is needed to render a silent video.
soundfile                    # reads and writes the spoken wavs

# Kokoro-82M, Apache-2.0, local and free. The lightweight fallback: its speakers
# are fixed embeddings, so a paragraph in the middle of a film sounds like the
# one at the start. Two packages exist for the same model -- the PyTorch one
# (`kokoro`) requires Python < 3.13 and pulls its own torch, so this is the
# onnxruntime one, which runs anywhere and touches nothing. Its weights are a
# separate ~350MB download: bash tools/get_kokoro.sh
kokoro-onnx

# Chatterbox plus Chatterbox Turbo, MIT licensed, local and free. Turbo is the
# preferred English podcast voice and clones one authorized reference WAV per
# host. This replaces Qwen3-TTS; keeping both is impossible under their current
# exact Transformers pins.
chatterbox-tts
# Chatterbox's PerTh watermark package still imports pkg_resources. Setuptools
# 81+ removed it; Torch only requires >=77, so this overlap keeps both valid.
setuptools>=77,<81
