================================================================================
RETRO AI ARENA & STUDIO - COMMAND REFERENCE GUIDE
================================================================================

NOTE ON GAME IDs: a game id must match `python studio.py --list-games` EXACTLY,
including the "-v0" integration suffix. "SuperMarioBros3-Nes" fails with
"No romfiles found"; the real id is "SuperMarioBros3-Nes-v0". The ids below are
ones that ship imported; run --list-games to see what is on YOUR system.


1. PLAYING GAMES (STUDIO CLI)
--------------------------------------------------------------------------------
# Single Player (Human alone, starting from title / boot screen)
python studio.py --game SuperMarioBros3-Nes-v0 --boot-screen

# Single Player with custom window scale (e.g. 4x or 5x for modern high-res monitors)
python studio.py --game SuperMarioBros3-Nes-v0 --scale 5 --boot-screen

# Single Player in full-screen mode (aspect-ratio preserved)
python studio.py --game SuperMarioBros3-Nes-v0 --fullscreen --boot-screen

# Two Human Players (Hot-seat / 2 Gamepads or Gamepad + Keyboard)
python studio.py --game DoubleDragon-Nes-v0 --two-human --boot-screen

# Two Human Players Co-Op (e.g. TMNT: The Arcade Game)
python studio.py --game TeenageMutantNinjaTurtlesIITheArcadeGame-Nes-v0 --two-human --mode coop --boot-screen

# Human (P1) vs Trained AI Bot (P2)
python studio.py --game DoubleDragon-Nes-v0 --players 2 --model ./checkpoints/DoubleDragon-Nes-v0/best_model.zip

# Co-Op Human (P1) + Trained AI Bot (P2)
python studio.py --game TeenageMutantNinjaTurtlesIITheArcadeGame-Nes-v0 --players 2 --mode coop --model ./checkpoints/TeenageMutantNinjaTurtlesIITheArcadeGame-Nes-v0/iter_250.zip


2. LISTING & IMPORTING GAMES
--------------------------------------------------------------------------------
# List only games with verified imported ROMs installed on your system
python studio.py --list-games

# List all game definitions known to stable-retro (including unimported games)
python studio.py --list-all-games

# Import ROMs into stable-retro from a folder
python -m retro.import /path/to/your/roms

# Match a ROMs/ folder against stable-retro's hash databases (headered or not) and import
python tools/import_fixer.py


3. AI WRITER & CAPTION GENERATION
--------------------------------------------------------------------------------
# Auto Cascade (DEFAULT): Claude Code subscription -> Anthropic API -> Gemini -> Ollama
python studio.py --game SuperMarioBros3-Nes-v0 --writer auto

# Force Google Gemini (requires GEMINI_API_KEY environment variable)
python studio.py --game SuperMarioBros3-Nes-v0 --writer gemini --gemini-model gemini-2.5-flash

# Force Claude Code CLI (uses existing Claude subscription)
python studio.py --game SuperMarioBros3-Nes-v0 --writer claude-code

# Force Claude API (requires ANTHROPIC_API_KEY)
python studio.py --game SuperMarioBros3-Nes-v0 --writer claude --claude-model claude-opus-4-8

# Force Local Ollama (Free, runs offline on local GPU)
python studio.py --game SuperMarioBros3-Nes-v0 --writer ollama --writer-model qwen3:30b-a3b


4. RE-STAGING & VIDEO GENERATION (WITHOUT REPLAYING)
--------------------------------------------------------------------------------
# Re-run the writing/rendering from an existing capture (no emulator). Point it at
# the *_source.mp4 inside a staged folder; --list-games shows the exact game ids.
python studio.py --game SuperMarioBros3-Nes-v0 --from-mp4 ./studio_out/<folder>/<slug>_source.mp4

# Re-render only, from an edited overlays.json (wording / style), in seconds:
python restyle.py ./studio_out/<folder>


5. TRAINING AI AGENTS (REINFORCEMENT LEARNING)  [deferred half -- see CLAUDE.md]
--------------------------------------------------------------------------------
# Train a single-player policy with PPO
python train.py --game SuperMarioBros3-Nes-v0 --timesteps 500000 --num-envs 8

# Train with Self-Play (two-player games)
python train.py --game DoubleDragon-Nes-v0 --mode versus --self-play --timesteps 1000000

# Train with Co-Op reward sharing
python train.py --game TeenageMutantNinjaTurtlesIITheArcadeGame-Nes-v0 --mode coop --timesteps 1000000


6. AUDIT & DIAGNOSTIC TOOLS (Located in tools/)
--------------------------------------------------------------------------------
# Inspect live RAM addresses and data variables during a replay
python tools/audit_ram.py --game SuperMarioBros3-Nes-v0

# Detect on-screen ? blocks / tiles for a game
python tools/inspect_blocks.py --game SuperMarioBros3-Nes-v0

# Discover a RAM variable's address from a recorded demo
python tools/find_game_vars.py --demo ./recordings/<your>.bk2


7. TROUBLESHOOTING CONTROLLERS (WSL)
--------------------------------------------------------------------------------
# ONE tool does the whole diagnosis, in order:
#   Phase 0  OS / WSL /dev/input permission audit (the layer that usually bites)
#   Phase 1  SDL / pygame enumeration
#   Phase 2  live button / axis / d-pad / auto-fire probe
python tools/probe_pad.py

# Just the permission + enumeration checks, no live probe:
python tools/probe_pad.py --no-probe

# If a pad enumerates in Linux but is dead in the game, the event nodes are
# usually not readable by SDL. Quick fix (lost on replug / wsl --shutdown):
sudo chmod a+r /dev/input/event* /dev/input/js*

# Durable fix -- join the input group, then restart WSL from Windows:
sudo usermod -aG input $USER      # then, in Windows:  wsl --shutdown

# Attaching the pads to WSL in the first place (from an ADMIN PowerShell):
usbipd list
usbipd bind   --busid <id>        # once per device
usbipd attach --wsl --busid <id>  # every replug and every wsl --shutdown
